## Landing Pages

**Category:** Navigation | **Team:** Dev team | **Type:** Technical

**Priority:** Medium | **Status:** Submitted to client

#### Recommendation

{% recommendation %}
Creating clear categorization and landing pages is important, but too many pages with fairly identical content should not be created, because this creates internal competition on the site — meaning different pages on your site compete to rank for the same keywords. That's why we have suggested that some category pages that are too deep should be removed. For example, on the Christmas and New Year page (https://ekvator.bg/oferti/koleda-i-nova-godina-202021/45), there is no need for an Egypt subcategory (https://ekvator.bg/oferti/koleda-i-nova-godina-202021/egipet/kajro-i-hurgada/45/38/282).
{% /recommendation %}

## All Products Page

**Category:** Navigation | **Team:** Dev team | **Type:** Technical

**Priority:** Medium | **Status:** Submitted to client

#### Recommendation

{% recommendation %}
Develop a /products/ (All Products) page displaying all products on the site (from all categories). Similar to https://demo.onlime.bg/batteryland/bg/browse/?inPromo=1. There is no need to include child products, only the main ones. For example:

https://demo.onlime.bg/batteryland/bg/product/laptop-battery-a41-k56-144v-2200mah - included
https://demo.onlime.bg/batteryland/bg/product/laptop-battery-a41-k56-144v-2200mah/s550-series - not included
{% /recommendation %}
