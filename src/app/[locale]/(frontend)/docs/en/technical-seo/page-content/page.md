## Similar Content

**Category:** Page content | **Team:** Content team | **Type:** Technical

**Priority:** Medium | **Status:** Submitted to client

#### Recommendation

{% recommendation %}
Pages with similar content. It is recommended to add unique paragraphs (minimum 200 words) and H1 (heading 1) tags on these pages to improve their uniqueness.
{% /recommendation %}

## PDF Files

**Category:** Page content | **Team:** Content team | **Type:** Technical

**Priority:** Medium | **Status:** Submitted to client

#### Recommendation

{% recommendation %}
Separate blog content available as PDF documents (e.g. https://fortonhomes.com/stpka-po-stpka/).

It is recommended to publish all studies as separate HTML pages with an option to download them as PDF. This way the content will be better indexed and more accessible for ranking.
{% /recommendation %}

## Home page

**Category:** Page content | **Team:** Content team | **Type:** Technical

**Priority:** High | **Status:** Submitted to client

#### Recommendation

{% recommendation %}
The homepage needs to be optimized by adding more unique content that delivers value to the user. Currently the page serves merely as navigation to the site's other main categories.

It would be good to add content to the homepage in the following sections:

- Who We Are?
- From the Builder
- Our Offers
- Luxury Properties
  {% /recommendation %}
