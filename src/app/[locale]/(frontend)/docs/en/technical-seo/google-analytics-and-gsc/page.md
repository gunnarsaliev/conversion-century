## Goals

**Category:** Google Analytics & GSC | **Team:** Dev team | **Type:** Technical

**Priority:** High | **Status:** Submitted to client

#### Recommendation

{% recommendation %}
There are no goals set up for tracking in Google Analytics. It is recommended that you add goals and events for all contact forms and key conversions.
{% /recommendation %}

## GSC and GA4

**Category:** Google Analytics & GSC | **Team:** Dev team | **Type:** Technical

**Priority:** High | **Status:** Submitted to client

#### Recommendation

{% recommendation %}
There is no connection between Google Analytics and Search Console. It is recommended that you link the two systems so they can exchange data. More information here: https://support.google.com/analytics/answer/1308621?hl=en
{% /recommendation %}
