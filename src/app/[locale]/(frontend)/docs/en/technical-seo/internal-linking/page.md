## Related Products

**Category:** Internal linking | **Team:** Dev team | **Type:** Technical

**Priority:** Medium | **Status:** Submitted to client

#### Recommendation

{% recommendation %}
It is recommended to add "related projects" below the description of each project (https://cwforton.com/bg/projects/logistics-industrial/stambolovo-factory/ should have 3-4 related projects and quick links to them at the bottom of the page)
{% /recommendation %}

## Popular Searches

**Category:** Internal linking | **Team:** Dev team | **Type:** Technical

**Priority:** Medium | **Status:** Submitted to client

#### Recommendation

{% recommendation %}
Listing pages should have a "Popular Searches" section at the bottom with links to similar landing pages. For example, nearby neighborhoods / similar property types.
{% /recommendation %}

## Blog Articles

**Category:** Internal linking | **Team:** Dev team | **Type:** Technical

**Priority:** Medium | **Status:** Submitted to client

#### Recommendation

{% recommendation %}
Each blog article should end with a "Read more" section and links to 3 other articles from the blog.
Example: https://myflex.bg/3-reasons-why-coworking-became-so-popular/
{% /recommendation %}

## Categories and Subcategories

**Category:** Internal linking | **Team:** Dev team | **Type:** Technical

**Priority:** Medium | **Status:** Submitted to client

#### Recommendation

{% recommendation %}
Each category and subcategory should have quick links at the bottom of the page:

Main categories: (Example: https://baniashop.bg/product-category/toaletni-i-bideta/ should have "Browse more" and a link to https://baniashop.bg/product-category/mivki-i-konzoli/, https://baniashop.bg/product-category/vani/ and https://baniashop.bg/product-category/mebeli-za-bania/.

Subcategories: (Example: https://baniashop.bg/product-category/toaletni-i-bideta/monoblok/ should have "Browse more" and a link to https://baniashop.bg/product-category/toaletni-i-bideta/visyashti-toaletni-chinii/, https://baniashop.bg/product-category/toaletni-i-bideta/strukturi-za-vgrajdane/, https://baniashop.bg/product-category/toaletni-i-bideta/bideta/ - these can be selected on a random basis.
{% /recommendation %}

## Broken Internal Links

**Category:** Internal linking | **Team:** Dev team | **Type:** Technical

**Priority:** Medium | **Status:** Submitted to client

#### Recommendation

{% recommendation %}
Broken internal links. It is recommended to point them to working pages or redirect them with 301 redirects.
