## Schema Markup

**Category:** Schema markup | **Team:** Dev team | **Type:** Technical

**Priority:** High | **Status:** Submitted to client

#### Recommendation

{% recommendation %}
The site is missing structured data (Schema Structured Data). It is recommended that the site include:

- **Organization**: on the homepage.
- **Website**: applied globally (currently OK).
- **BreadcrumbList**: globally.
- **Product** and **SingleFamilyResidence**: on all listings.
- **Article**: on blog posts.
- **Local Business**: on location pages.
- **Video**: on all videos.
  {% /recommendation %}
