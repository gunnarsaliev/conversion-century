## Meta keywords

**Category:** Keywords | **Team:** Dev team | **Type:** Technical

**Priority:** Medium | **Status:** Submitted to client

#### Recommendation

{% recommendation %}
Pages with meta keywords tags (Meta Keywords). It is recommended to remove these tags from the site.

All search engines (including Google) have ignored the `meta keywords` tag for years, and its only current use is to reveal your target keywords to competitors.
{% /recommendation %}
