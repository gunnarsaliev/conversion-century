---

## H1

**Category:** H1 | **Team:** Dev team | **Type:** Technical

**Priority:** High | **Status:** Submitted to client

#### Recommendation

{% recommendation %}
Pages with missing Heading 1. It is recommended that you edit the HTML templates of all these pages to ensure at least one heading 1 tag on every page.
{% /recommendation %}

---

## More than 1 H1

**Category:** H1 | **Team:** Dev team | **Type:** Technical

**Priority:** Medium | **Status:** Submitted to client

#### Recommendation

{% recommendation %}
On a specific page there are 2 H1 tags. Example: `https://address-new.vjsoft.net/sofia-suha-reka-etazh-ot-kashta-offer440732`.

The secondary H1 tag should be removed if it is not shown to the user.
{% /recommendation %}

---

## Duplicate H1s

**Category:** H1 | **Team:** Dev team | **Type:** Technical

**Priority:** Medium | **Status:** Submitted to client

#### Recommendation

{% recommendation %}
Several pages have duplicate H1 tags. They need to be edited by adding at least 1-2 words to differentiate them.
{% /recommendation %}

---

## H1 with keywords

**Category:** H1 | **Team:** Dev team | **Type:** Technical

**Priority:** Medium | **Status:** Submitted to client

#### Recommendation

{% recommendation %}
The H1 on every page should include the target keywords for that specific page.
{% /recommendation %}
