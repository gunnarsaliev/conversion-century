## H1

**Category:** H1 | **Team:** Dev team | **Type:** Техническа

**Priority:** Висок | **Status:** Подадено към клиент

#### Recommendation

{% recommendation %}
Страници с липсващи Heading 1. Препоръчително е да редактирате HTML бланките на всички тези страници, за да гарантирате поне един heading 1 таг на всяка страница.
{% /recommendation %}

---

## Повече от 1 H1

**Category:** H1 | **Team:** Dev team | **Type:** Техническа

**Priority:** Среден | **Status:** Подадено към клиент

#### Recommendation

{% recommendation %}
При конкретен обект съществуват 2 броя H1 тагове. Пример: `https://address-new.vjsoft.net/sofia-suha-reka-etazh-ot-kashta-offer440732`.

Да се премахне второстепенният H1 таг, ако не се показва за потребителя.
{% /recommendation %}

## Дублирани H1

**Category:** H1 | **Team:** Dev team | **Type:** Техническа

**Priority:** Среден | **Status:** Подадено към клиент

#### Recommendation

{% recommendation %}
Няколко страници са с дублирани H1 тагове. Нужно е да се редактират, като се добави поне 1-2 думи, с които да се различават.
{% /recommendation %}

---

## H1 с ключови думи

**Category:** H1 | **Team:** Dev team | **Type:** Техническа

**Priority:** Среден | **Status:** Подадено към клиент

#### Recommendation

{% recommendation %}
H1 на всяка страница трябва да включва ключовите думи, които таргетираме на определената страница.
{% /recommendation %}
